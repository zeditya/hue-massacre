## `AI_CHAT_HISTORY.pdf` — REQUIRED, not yet added

The assignment requires **one PDF** containing **all** of the AI chats used to
build this project, as **selectable text** (screenshots do not count):

1. This coding-agent session, start to finish.
2. Your Claude / other AI chat(s).

Export each as text, merge them into a single PDF with a short contents page, and
save it here as `AI_CHAT_HISTORY.pdf`. Until that file exists, the *AI chat
history* link at the top of the README is dead.

How to check it is right: open the PDF and try to **highlight and copy a
sentence**. If you cannot, it is images and will lose marks — re-export as text.

## `AI_CHAT_HISTORY.pdf` checklist

- [ ] Every chat included, nothing cherry-picked
- [ ] Selectable text, not screenshots
- [ ] Single merged PDF with a contents page
- [ ] Named exactly `AI_CHAT_HISTORY.pdf`
- [ ] Lives in this folder, linked from the README
